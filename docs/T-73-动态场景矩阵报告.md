# T-73 动态场景矩阵报告

## 结论

T-73 放行。组 B（H1–H10）与组 C（I1–I6）共 16 个场景全部完成浏览器实测，动态场景通过率为 **16/16（100%）**。

## 组 B

| 场景         | 实测结果                                               |
| ------------ | ------------------------------------------------------ |
| H1 下拉面板  | 新增 `role=listbox` 被识别为 `listbox/portaled=true`   |
| H2 远程下拉  | 输入后同时等待真实请求响应和异步 option 出现           |
| H3 日期面板  | 按既定优先级直接写入标准化日期值，不依赖临时面板       |
| H4 确认弹窗  | 全页两个“确定”，dialog scope 内唯一命中                |
| H5 条件字段  | 字段出现、消失、再次出现均按新 DOM 状态解析            |
| H6 动态增行  | 通过行文本 scope 唯一定位同构行内按钮                  |
| H7 折叠面板  | 展开前无内容，点击后懒渲染内容可见                     |
| H8 分步向导  | 下一步替换前一步 DOM，旧按钮消失、新状态出现           |
| H9 抽屉      | 动态 `.el-drawer` 内标题唯一可见                       |
| H10 虚拟列表 | 实现并验证“有搜索先筛选；无搜索按视口分段滚动”两条路径 |

## 组 C

| 场景          | 实测结果                                                                                |
| ------------- | --------------------------------------------------------------------------------------- |
| I1 二级菜单   | 叶子菜单在前置点击后才出现，并在 menu scope 内命中                                      |
| I2 SPA 路由   | 同时验证 URL pattern 与新页面 heading，不依赖 load 事件                                 |
| I3 tabs       | tabpanel 从不存在到懒渲染可见                                                           |
| I4 面包屑返回 | 返回后表单为新状态，未假设旧填写值仍存在                                                |
| I5 新标签页   | 通过 BrowserContext 捕获新 page 并在该 page 校验内容                                    |
| I6 iframe     | 新增 `frame-playwright` 契约，回放通过 `frameLocator(frame).locator(selector)` 执行动作 |

## 代码交付

- `LocatorStrategy`/schema 新增 `frame-playwright`，显式携带 frame 与 frame 内 selector。
- UI 回放支持 iframe click/fill；禁止把 iframe target 与外层 DOM scope 混用。
- 新增 `resolveVirtualItem`：搜索优先，否则分段滚动，到达末端仍未命中时明确失败。
- `e2e/t73-dynamic-matrix.spec.ts` 保存全部 16 个场景桩和实测断言。

这些数据满足 T-75 的动态场景决策输入；未修改定位引擎默认值，也未删除 legacy。
