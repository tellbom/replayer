## 2. T-105 定级结论与证据

结论：**P0（静默错误）**。

修复前复现使用两个不同 source、相同 `name`、相同初始值的标准 DOM 控件。分析器将它们合并为单一参数 `shared`，生成的两个 UI 填充和请求体字段都引用 `{{shared}}`。回放传入单个 `replay-value` 后，服务端实际接收到两个字段均为该值并接受提交。因此存在“来源被错误合并后仍真正提交且服务端接受”的路径，符合 P0 定义。

修复后，同值控件按各自 source lineage 生成两个独立参数；验收用例 `e2e/t105-source-lineage.spec.ts` 覆盖复现与修复状态。根据裁决，P0 不触发存量测试数据迁移。

## 3. Definition of Done

1. F-1：同一次 navigation 实例内提取并消费页面动态值，通过 T-103 E2E。
2. F-2：异常动作不再导致 analyzer 整体崩溃，通过单元测试。
3. F-4：不同 source 不因值相同而合并，通过 T-105 P0 回归。
4. identity：A → B 阻断且副作用为 0；A → A 通过，通过 T-106 E2E。
5. enum：静态与 contextual 分离；V-108-8 上游联动枚举判为 contextual。
6. cold start：按实际 navigation 收敛；无跳转、多跳转、持续不收敛及 attached 模式均覆盖。
7. 通用性：`packages/*` 新增行扫描未发现 OA、fixture、固定端点、框架或认证产品特判。
8. 安全：无来源值保留 TODO；不自动猜常量；响应丢失不重复 mutating request；identity、semantic-drift、postcondition 护栏保持有效。
