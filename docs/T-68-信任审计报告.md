## A4：官方 Playwright Codegen 对照

对相同 DOM 和相同六个目标，调用当前安装的官方 Playwright console/codegen 路径 `playwright.generateLocator(element)`，原始输出如下：

```text
getByRole('button', { name: '搜索A' })
locator('section:nth-child(8) > ._btn_b')
getByRole('button', { name: '搜索C' }).nth(1)
getByRole('button', { name: '搜索D' }).nth(1)
getByRole('button', { name: '提交E' })
getByRole('button', { name: '搜索F' }).nth(1)
```

DSH 的六项产物与官方输出逐项同构：A/E 为 role+name，B 为结构 CSS，C/D/F 为 role+name+nth。DSH 对含位置依赖的 B/C/D/F 降为 LOW，属于本项目置信度规则，不是生成器偏差。

## A5：`addInitScript` 闭包捕获排查

产品代码中的调用只有两组：

- `packages/browser/src/context.ts`：三个 IIFE 均通过 `{ content }` 注入；engine 通过函数参数传入；
- `packages/recorder/src/session.ts`：IIFE 均通过 `{ content }` 注入；布尔常量使用零捕获函数；engine 通过函数参数传入。

测试代码中的调用均为 `{ content }` 或零捕获函数。未发现仍由 `addInitScript` 闭包捕获外层变量的调用。

## 机械防护与竞态修复

- `launchDSHContext` 在返回前创建审计页，校验 `__DSH_LOCATOR__`、`__DSH_SNAPSHOT__`、`__DSH_GEN__`、`__DSH_LOCATOR_ENGINE__`；缺失立即抛出 `[注入自检失败]`。
- 录制当前页安装探针后再次校验同四项，避免“context 注册成功、当前页未生效”。
- 探针为每个动作分配 `actionIdx`，点击元素写入 `__dsh_clicked__[actionIdx]`；Node 消歧只读取对应动作的元素，不再使用单一 `__dsh_last_clicked__`。
- 快速连续点击两个 LOW 元素的 E2E 已验证两次回调分别得到各自原元素。
