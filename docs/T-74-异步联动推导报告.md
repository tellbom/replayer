# T-74 异步联动推导报告

## 结论

T-74 放行。录制器已能从动作时间窗内的真实 XHR/fetch 响应与表单最终值推导 `waitAfter.requestUrlPattern` 和 `waitAfter.notEmpty`；回放在动作执行前挂载响应监听，并在响应后等待目标字段非空，不依赖固定 `sleep`。

## 实现

- `RecordedAction.waitAfter` 与技能契约对齐，支持 `urlPattern`、`networkIdle`、`requestUrlPattern` 和语义 `notEmpty`。
- 录制结束时按 `requestTs` 关联动作后 2 秒内且早于下一动作的成功 XHR/fetch；仅当响应标量值与带标签表单控件的非空值明确相等时写入等待契约。
- 请求等待使用 URL pathname；审批人控件被推导为 `{ strategy: el-form-item, label: 审批人, kind: input }`。
- UI 回放在执行动作前创建 `waitForResponse`，随后依次等待响应及语义控件非空；显式 `settleMs` 仍只服务已有 scope 动画契约。
- 修正录制探针只注入当前文档的问题：探针同时注册为 init script，业务页导航后仍能采集动作。

## 验收证据

   - 无 `settleMs`
